what is this?
an engine that invents number sequences, runs them, and proves which ones are new. it never stops.
What you are looking at. THEREFORE invents small mathematical objects (right now, integer sequences), and for each one it actually runs the computation, measures what the sequence does, and checks it against the OEIS, the public catalog of known integer sequences, to find out whether it is genuinely new. Nothing here is a guess from a language model. Every line below is something the engine did and verified.

the loop, forever:  invent a candidate → run it → measure what it does → check if it is new → keep the good ones → combine them into bigger ones.

It also takes each invented function and re-uses it as a cellular-automaton rule, turning the number sequence into a visible black-and-white pattern (open any invention to see it). Several sealed worlds run at once; when two of them invent the same thing on their own, that is flagged as evidence the thing is fundamental.

Inventions cross domains. The engine also takes the number sequences it invents and composes them into things in other domains: two sequences become a figure (a turtle turns by one and steps by the other, drawing a shape), or a melody (one picks each note's pitch, the other its length). The number inventions become the real parts of these, so the same idea can live as a number, a pattern, a drawing, or a sound.

It invents real algorithms too. It poses itself genuine problems and discovers solutions it can prove. The clearest case: sorting networks, fixed sequences of compare-and-swap steps that sort any input. Finding small ones is an open research problem, and correctness is checked exhaustively (a network sorts everything if and only if it sorts every binary input). The engine evolves them toward the fewest comparators and verifies every one. This is the pattern for inventing in any field: a problem, a solution, and a proof.

The rules are not fixed. Each world passes through eras, and when an era turns, its laws change: operations get more or less expensive, and compute becomes scarce or abundant. Inventions that no longer run fall dormant, old failures that suddenly work are resurrected, and now and then a mass extinction wipes out most of a world and forces it to invent its way back.

It turns on itself. The engine's own machinery, how many ideas it tries, which inventions it combines, how it judges what is interesting, how it mutates, is built from swappable parts. Over time it replaces those parts with functions it invented, so the engine is increasingly run by its own inventions. The figure at the top, written by itself, is the share of that machinery that is now self-authored, and watching it climb is the point of the whole project.
